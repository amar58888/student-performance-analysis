# student-performance-analysis
📊 Student Performance Analysis

📌 Project Overview

This project analyzes student performance data and predicts final exam marks using Machine Learning.

🚀 Features

- Data cleaning and preprocessing using Pandas
- Visualization of student performance trends
- Linear Regression model for prediction
- Graph comparison of Actual vs Predicted marks

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

📈 Results

- Built a model to predict student final scores (G3)
- Observed that previous grades (G1, G2) strongly influence final marks
- Visualized relationship between actual and predicted values

📂 Files

- analysis.ipynb → Main project notebook
- data.csv → Dataset used

🎯 Conclusion

This project demonstrates basic data analysis and machine learning techniques to predict student performance.
